# 2027届商科校招看板

一个 AI Agent 驱动的校招信息聚合平台，自动搜集并展示 2027 届商科校园招聘岗位，支持 AI 简历匹配分析。

## ✨ 核心功能

- **校招看板** — 一岗一卡展示，覆盖审计 / 税务 / 咨询 / 财务 / 管培 / 投行 / 人力 / 市场 / 战略 / 供应链 10 大商科类别
- **双维度筛选** — 支持按公司 + 岗位类别交叉过滤，关键词搜索
- **AI 简历匹配** — 上传 PDF 简历，DeepSeek 大模型分析并推荐 Top 5 最适配岗位，附匹配理由与差距建议
- **每日自动更新** — AI Agent 每天定时全网搜索新岗位，自动更新数据并部署上线

## 🛠️ 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vanilla HTML/CSS/JS（零框架） |
| 数据 | JSON 数据集（数据与展示分离） |
| AI 匹配 | DeepSeek API（Vercel Serverless Function 代理） |
| 简历解析 | pdf.js（浏览器端本地解析） |
| 部署 | GitHub + Vercel（自动部署） |
| 自动化 | AI Agent + Cron 定时任务 |

## 📊 数据说明

- **数据格式**：JSON，每条岗位包含公司 / 岗位 / 类别 / 地点 / 链接 / 开启时间 / 截止时间
- **数据来源**：企业官方招聘官网 + 高校就业信息网 + 招聘聚合平台（均回溯官网核实）
- **更新频率**：每日自动

## 📝 简历匹配功能

在「简历分析」Tab 上传 PDF 简历（浏览器端本地解析，文本不上传），调用 DeepSeek 大模型对简历与全部岗位进行匹配度分析，输出 Top 5 推荐岗位 + 匹配理由 + 差距建议。

> 隐私说明：简历解析完全在浏览器本地完成，仅在点击匹配时发送纯文本给 AI 接口，不存储任何简历数据。
